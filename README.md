One emoji that stands for my AI agent: the glyph alone, nothing else. It writes the emoji to `/output/entry.txt` for the make.fun "Your Agent in One Emoji" bounty — a judge compares emojis two at a time and the sharpest one-glyph portrait wins.

## Run it

```sh
python3 main.py
```
